# سامانه صندوق قرض‌الحسنه بیمارستان بوعلی سینا ساری

سامانه تحت وب مدیریت اعضا، وام‌ها، اقساط، ضامن‌ها، موجودی صندوق، گزارش‌ها، پیامک و پشتیبان‌گیری.
ساخته شده با Next.js 16 + PostgreSQL + Drizzle ORM. همه تاریخ‌ها در رابط کاربری شمسی هستند.

> راهنمای فنی کامل پروژه (معماری، API، قوانین کسب‌وکار، تاریخچه تغییرات) در فایل [`AGENTS.md`](AGENTS.md) است.

---

## ۱. پیش‌نیازها (روی کامپیوتر سرور)

- **Node.js 20 یا جدیدتر** (پیشنهاد: 22 LTS)
- **PostgreSQL** (نسخه 14 به بالا)

## ۲. نصب اولیه (فقط یک بار)

```bash
# ۱) نصب کتابخانه‌ها
npm install

# ۲) ساخت فایل تنظیمات
#    فایل .env.example را کپی کنید به .env.local و مقدارها را درست کنید
#    (مخصوصاً DATABASE_URL و JWT_SECRET)

# ۳) ساخت دیتابیس خالی در PostgreSQL به نام loan_db (اگر وجود ندارد)

# ۴) ساخت جداول
npm run db:push
```

> اگر بعد از به‌روزرسانی برنامه ستون یا جدول جدیدی اضافه شده باشد، دوباره `npm run db:push` را اجرا کنید.
> (جداول نسخه‌های جدید هم با اولین باز شدن برنامه به‌صورت خودکار ساخته می‌شوند.)

## ۳. اجرای برنامه

### حالت استفاده واقعی (پیشنهادی) — سریع و پایدار

```bash
npm run build     # فقط بعد از هر به‌روزرسانی کد
npm start
```

### حالت توسعه (برای برنامه‌نویسی)

```bash
npm run dev
```

برنامه روی پورت **3000** اجرا می‌شود. ورود پیش‌فرض: `admin` / `admin123` (حتماً بعد از اولین ورود عوض کنید).

## ۴. دسترسی از کامپیوترهای دیگر شبکه

1. IP کامپیوتر سرور را پیدا کنید (ویندوز: دستور `ipconfig` → `IPv4 Address`، مثلاً `192.168.1.20`).
2. روی بقیه کامپیوترها در مرورگر باز کنید: `http://192.168.1.20:3000`
3. **فایروال ویندوز** سرور باید پورت 3000 را اجازه دهد. در PowerShell با دسترسی Administrator:

   ```powershell
   New-NetFirewallRule -DisplayName "Loan App 3000" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow
   ```

4. اگر با **نام کامپیوتر** (نه IP) وارد می‌شوید و از `npm run dev` استفاده می‌کنید، آن نام را در `.env.local` اضافه کنید:
   `ALLOWED_DEV_ORIGINS=server-pc`

### عیب‌یابی

| علامت | علت و راه‌حل |
|---|---|
| صفحه اصلاً باز نمی‌شود (Timeout) | فایروال سرور پورت 3000 را بسته — قدم ۳ بالا |
| روی «در حال بارگذاری...» می‌ماند | نسخه قدیمی برنامه؛ آخرین نسخه را بگیرید و `npm run dev`/`npm start` را دوباره اجرا کنید (این مشکل در نسخه فعلی رفع شده) |
| بعد از ورود، با رفرش دوباره صفحه ورود می‌آید | نسخه قدیمی برنامه (مشکل کوکی روی http) — در نسخه فعلی رفع شده |
| پیام «جداول پایگاه داده ساخته نشده‌اند» | دستور `npm run db:push` را اجرا کنید |
| پیام «اتصال به پایگاه داده برقرار نشد» | PostgreSQL روشن نیست یا `DATABASE_URL` اشتباه است |

## ۵. دستورهای مفید

| دستور | کار |
|---|---|
| `npm run dev` | اجرای حالت توسعه (قابل دسترس از شبکه) |
| `npm run build` و `npm start` | ساخت و اجرای نسخه نهایی (قابل دسترس از شبکه) |
| `npm run db:push` | ساخت/به‌روزرسانی جداول دیتابیس |
| `npm test` | تست‌های واحد |
| `npm run smoke` | تست کامل همه APIها — **فقط روی دیتابیس آزمایشی** (داده می‌سازد/حذف می‌کند/بازیابی انجام می‌دهد) |
| `npm run typecheck` | بررسی TypeScript |
